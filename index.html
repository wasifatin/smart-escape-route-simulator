Instructions

  1. Import a building JSON file.
  2. Select a room or junction as your starting point.
  3. The application calculates the lowest-cost route to an open exit.
  4. Block rooms, junctions or corridors to simulate hazards.
  5. Close exits to simulate unavailable exits.
  6. The route is recalculated automatically.
  7. Use Reset to restore the original condition.
